# Частые проблемы

## Сборка

| Симптом | Причина | Решение |
|---|---|---|
| `cmake: command not found` | CMake не в `PATH` | Открыть проект в CLion или добавить CMake в `PATH` |
| `CMAKE_CXX_COMPILER not found` | Нет компилятора в `PATH` | Использовать toolchain CLion или установить GCC/Clang/MSVC |
| Долго висит `FetchContent` | Первая загрузка SDL3/pugixml | Проверить доступ к GitHub; при необходимости `LADOGA_USE_SYSTEM_SDL3=ON` |
| CMake не находит OpenGL | Нет dev-пакета | Установить `libgl1-mesa-dev` / `mesa-common-dev` (Linux) |
| `undefined reference to SDL_...` | Не подключён `SDL3::SDL3` | Собирать через CMake, не вручную |

## Запуск

| Симптом | Причина | Решение |
|---|---|---|
| Вместе с окном открывается консоль | Старый exe собран как CUI | Пересоберите проект; примеры 01–06 имеют `Windows GUI` |
| `0xC0000135` | Не хватает DLL | Запускать из `<build>/bin`, рядом лежит `libwinpthread-1.dll` |
| Окно не открывается, но виден диалог с ошибкой | Ошибка SDL/OpenGL/XML | Прочитать текст диалога; подробности — в `stderr` при запуске из терминала |
| Окно не открывается, код 1 | Нет OpenGL-контекста | Обновить драйвер видеокарты; посмотреть `stderr` |
| Текст не рисуется | Не найден шрифт | Проверить `build/bin/fonts/Roboto-Regular.ttf`; в сообщении будет предупреждение |
| Текст «квадратиками» | Шрифт без нужных глифов | Используется Roboto с кириллицей; проверить, что файл не повреждён |

## XML

Ошибки загрузки выбрасываются как `std::runtime_error` с путём, строкой и
колонкой:

```text
main.xml:12:5: неизвестный тег <Buton>
```

| Симптом | Причина | Решение |
|---|---|---|
| `неизвестный тег` | Опечатка или тег не реализован | Сверить с [XML_REFERENCE.md](XML_REFERENCE.md) |
| `неизвестный атрибут` | Свойство не поддерживается | Убрать атрибут или добавить его в PropertyMap |
| `Name 'x' уже используется` | Дубликат `Name` | Имена в одном окне уникальны |
| `свойство Text: ...` | `Text` у виджета, которому оно не положено | `Text` только у Label/Button/TextBox/CheckBox |
| `Min/Max: Min не может быть больше Max` | Неверный диапазон Slider | Исправить `Min`/`Max` |
| `не удалось открыть файл` | Неверный путь | Путь считается от рабочего каталога; используйте абсолютный путь |

## События

| Симптом | Причина | Решение |
|---|---|---|
| `Click="onOk"` ничего не делает | Действие не зарегистрировано | `register_action("onOk", ...)` |
| Кнопка не реагирует | Клик вне границ | `clicked` срабатывает только при нажатии и отпускании внутри |
| TextBox не принимает ввод | Нет фокуса | Кликните по TextBox; фокус ставится по нажатию |
| `действие '...' не зарегистрировано` | Опечатка в имени | Имя в `Click` и `register_action` должно совпадать |
