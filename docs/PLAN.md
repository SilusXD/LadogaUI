# План работы: маленькие шаги

План разбит так, чтобы один шаг занимал **10–25 минут** и давал проверяемый
результат. Шаги не перескакиваем: каждый следующий опирается на предыдущий.

## Как работать с планом

1. **Сначала шаг пробуешь ты.** Если через 20–25 минут нет результата — пишешь
   мне номер шага (например, «застрял на 1.4») и текст ошибки. Я объясняю или
   делаю этот шаг.
2. После каждого шага: сборка, `ctest`, ручная проверка, коммит.
3. Если шаг оказался больше, чем на 25 минут, — режем его ещё на два.
4. Галочку ставим только после проверки, а не после «написал код».
5. Публичный API меняем только через `docs/API_CONTRACT.md`.
6. Временное упрощение помечаем `// TODO: упрощение для этапа N`.

Текущая точка: **этапы 4–5 закрыты**, этап 6 — документация готова, остался
тест «30 минут» на человеке и финальный коммит.
