## Правила перехода между этапами

1. Этап считается готовым только после сборки, `ctest` и ручной проверки
   критерия готовности.
2. Каждый этап заканчивается отдельным коммитом и обновлением этого файла.
3. Новый виджет на этапе 5 — это сразу: реализация, XML-пример, страница
   справки и тест.
4. Нельзя начинать следующий этап, если предыдущий «почти работает»: долги
   фиксируем в `PLAN.md` отдельными пунктами.
5. Публичный API меняется только через правку контракта, а не «по ходу кода».
